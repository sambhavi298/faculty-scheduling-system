## Known, deliberate simplifications (not bugs)

- Both the admin dashboard and the faculty self-stats endpoint refresh `faculty_appointment_stats` on every read rather than via a background job — no scheduler infrastructure exists anywhere in this codebase.
- JWTs cannot be revoked before expiry (stateless by design); logout is client-side-only. TTL kept short (12h) to bound exposure.
- Admin-created accounts get a one-time temporary password with no forced-change-on-first-login enforcement.
- Faculty Availability's "add exception" form has no way to list previously-added exceptions back (no `GET` exists for that table yet) — the frontend is honest about this in a notice banner rather than pretending otherwise.
- Admin has no delete/deactivate UI for any entity — matches the backend, which deliberately has none (no soft-delete column exists on this schema).
